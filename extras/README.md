# Optional projects

`pecofence-promo/` contains the Remotion source for the product videos. It is
independent of the Rust desktop application and is not built by the app's CI.

`clipboard-history/` documents the *Clipboard History* of Settings → Tools (the texts and
pictures copied on Windows, in a script fence), whose script is built into the app
(`crates/app/assets/scripts/clipboard-history.ps1`). See its README.

Recordings, audio renders, screenshots, Node dependencies and final videos remain
local. See the project's README and capture/generation scripts to regenerate them.
