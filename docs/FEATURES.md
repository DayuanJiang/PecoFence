# PecoFence 功能总表

以当前源代码为准。「怎么用」一列写的是默认操作方式；凡带「设置」的在托盘菜单 → 设置… 里，凡带「栅栏菜单」的是在栅栏标题栏或空白处右键（从上到下：收起、重命名 | 视图、排序方式、新建、粘贴、标签页 | 锁定位置和大小、栅栏选项…、删除栅栏 | 添加到桌面 ›，里面是新建栅栏、新建便签、新建小工具、在桌面显示文件夹；便签、时钟和脚本栅栏的第二组换成它们自己的项，「桌面」栏的删除栅栏换成为空时自动隐藏和像桌面一样排列），「栅栏选项」是栅栏菜单 → 栅栏选项…（即 设置 → 栅栏 页，逐个栅栏调整外观 / 布局 / 行为；正在调整的栅栏在桌面上带白色选中描边，离开这一页或关闭设置即消失），「项目菜单」是在图标上右键。

## AI + CLI：把桌面配置交给助手

PecoFence 内置 `pecofence-cli`，Claude Code、Codex、Cursor 等能运行本地命令的 AI 助手可以读取现有设置，直接配置正在运行的 PecoFence。你可以让助手切换主题、批量调整透明度和图标大小、创建栅栏与标签页、整理图标、编写自动规则，以及导入导出配置。

启动 PecoFence 后，把需求交给助手，例如：“先阅读 `pecofence-cli skill` 和 `pecofence-cli describe`，查看并备份我的配置，再切换为深色模式，把所有栅栏调得更透明。”Microsoft Store 版通过 PATH 调用；便携版需告诉助手 `pecofence-cli.exe` 的完整路径。

设置 → 整理规则 → AI 助手 → 「复制给 AI 助手的提示词」复制一段现成的整理请求，粘贴给助手即可：它让助手先读 `skill`，看过桌面项目和栅栏、导出配置备份后提出整理方案（新建哪些栅栏、项目放到哪里、为新文件加哪些规则），等你同意再执行；商店版的提示词写 `pecofence-cli`，安装版和便携版写这台电脑上 `pecofence-cli.exe` 的完整路径。「命令行文档」打开下面的上手指南（#87）。

JSON 输出报告实际改动，命令目录与 JSON Schema 帮助助手发现可用操作和参数。布局快照保存栅栏布局；全局设置和规则通过配置导入导出备份与恢复。详见 [CLI 上手指南与完整参考](CLI.md#start-with-your-ai-agent)。

## 1. 栅栏基础

| 功能 | 怎么用 | 备注 |
|---|---|---|
| 虚拟栅栏收纳桌面图标 | 首次启动自动建「程序 / 文件夹 / 文件与文档 / 桌面」四栏并按规则整理；前三个从屏幕右上角往下排成一列，每个都显示出全部图标行，右边一列放不下下一个时，它在左边另起一列（只有比整个屏幕还高的栅栏才滚动） | 整理不移动、不修改任何真实文件；真实桌面图标由 Explorer 同一开关隐藏，资源管理器忙时（刚登录、桌面上一下子多出上千个文件）栅栏照常能拖、能点，图标等资源管理器回答后再隐藏；退出恢复（打开「关闭 PecoFence 时保持 Windows 桌面图标隐藏」时保持隐藏，见下），崩溃有 watchdog 兜底：恢复桌面图标，并用同样的参数重新启动 PecoFence；因无响应被 Windows 结束（用户选了「关闭程序」）时也重新启动；运行不到 1 分钟就崩溃时，10 分钟内只重新启动一次，免得每次启动都崩溃时反复重启；被任务管理器结束、注销或关机时不重启；桌面上删掉的文件：亲手放进某个栅栏的，记录保留 7 天、最多 200 条（最旧的先删），这期间回到桌面（从回收站还原、重新下载）时回到原来的栅栏和位置；由规则或默认放进栅栏的不留记录，回来时规则再放一次 |
| 入门小技巧和新功能提示 | 自动（任务栏上方右下角的卡片，每张 30 秒，鼠标停在上面时不消失；右下角有栅栏时，卡片挪到离它最近、不盖住任何栅栏的地方） | 首次启动依次显示 4 条小技巧：拖框新建栅栏、双击桌面隐藏、速览和打字搜索（写出当前的快捷键；没有快捷键能打开速览时跳过这条）、拖到标题合成标签页；「下一条」看下一条，最后一条的按钮打开使用手册，× 或 30 秒不点就结束。从没有这条提示的版本升级后，第一次启动显示一次本版新功能，按钮「打开设置」打开「设置」→「速览与搜索」并滚到对话框跳转的演示。功能提示（设置 → 常规 → 桌面与启动 → 功能提示，默认开，CLI `settings set featureTips false`）：用得上某个功能时在同一位置出一张卡片，每张只出一次，以后不再出：① 自己新建栅栏（拖框或菜单，含在桌面显示文件夹）后，除「桌面」栏、标签页和小工具外有 4 个栅栏窗口时，「栅栏多了可以收起」（正文按「收起的栅栏怎么展开」的选择写悬停、单击或双击展开），按钮「知道了」；② 从栅栏用资源管理器打开同一个桌面文件夹（或指向文件夹的快捷方式）累计第 3 次，且没有文件夹栅栏显示它时，「把常用的文件夹放到桌面上」，「试一试」把它作为文件夹栅栏放在来源栅栏旁边，「不用」关掉；③ 本次运行里把同一扩展名的 3 个文件（不含文件夹、.lnk、.url，已有规则会放到这个栅栏的不算）从别的栅栏或资源管理器拖进同一个普通栅栏（粘贴不算），「让新文件自动进来」，「添加规则」在规则列表最前面加一条「.xxx 文件」扩展名规则，以后新的这类文件放进这个栅栏，「不用」关掉。另一张卡片正显示时不出，等下一次同样的情况；有两个按钮的卡片点正文不起作用。显示过哪条记在 config.json 旁的 `notices.json`；`--test-script` 和 `--exit-after` 启动时都不显示 |
| 新建栅栏 | 在空桌面上拖出一个不碰到任何栅栏的矩形 → 点矩形右下角的「新建栅栏」；托盘菜单 → 新建栅栏；栅栏菜单 → 添加到桌面 → 新建栅栏 | 松开后矩形右下角出现两个小按钮「在此显示文件夹…」和「新建栅栏」（右边缘和矩形对齐，下面放不下时放在矩形里面；Fluent 是 4 DIP 圆角，Liquid Glass 是胶囊形，随缩放比例变大）；它们不抢前台也不抢键盘，Delete、Esc、打字跳选、再拖一次都照常作用于桌面；不点的话 3 秒后淡出（指针停在按钮上时不消失），按 Esc 或在别处按下鼠标就立即消失；「新建栅栏」在画出的矩形里建一个栅栏并进入改名，「在此显示文件夹…」选一个文件夹，把它的文件夹栅栏放在画出的矩形里（文件夹已经显示在桌面上时只把那个栅栏显示出来）；矩形碰到栅栏、或者框选了 Windows 桌面图标时不出现；托盘菜单 / 栅栏菜单里的新栏放在源栏旁的空位，宽度正好整数列；设置 → 在桌面空白处拖出矩形时显示“新建栅栏”按钮（默认开，CLI `settings set offerNewFence false`）：关闭后拖出的矩形只框选栅栏 |
| 框选多个栅栏 | 在空桌面上拖出矩形，碰到的栅栏即被选中（拖动时实时显示）；按住 Ctrl 或 Shift 追加 | 选中的栅栏外围有一圈白色描边（外侧深色细线，与拖动时的落点白框一致）；隐藏桌面图标时自绘选框（淡白色填充 + 1 DIP 白色边框和外侧深色细线，位于栅栏下方）；锁定的栅栏不参与；单击桌面、单击任一栅栏或按 Esc 取消选择 |
| 移动 | 拖标题栏；拖选中栅栏之一的标题栏则整组一起移动 | 与其他栅栏和屏幕边缘 8 px 吸附（设置可关；间距可用 `snapping.gapPx` 调整）；放到另一个栅栏旁边或下面时，间距和顶边（左边）一起吸附；和同一行、同一列任意一个栅栏的边相差不到吸附距离（10 DIP）时对齐过去并显示参考线，两个栅栏隔得再远也一样（反馈 #100），离得远的不吸附间距；吸附不累积，窗口始终在手底下：每次鼠标移动都立即移动窗口，Liquid Glass 的玻璃在下一帧按新位置重画；整组移动时各栅栏保持相对位置，由整组的外框吸附到组外的栅栏和屏幕边缘，不会合并为标签页，Esc / 右键取消时整组回到原位，松开后与其他栅栏重叠的成员各自移到最近的空位；收起的栅栏按展开后的大小放：放在屏幕下方、展开会伸进任务栏或屏幕外时，松手后它上移到展开后正好在工作区里的位置（拖动时白框先显示落点），保存的位置就是窗口所在的位置，重启后不跳；收起的标题行之间仍可紧挨着排成一列（展开时推开下方栅栏）；判断重叠时按其他栅栏平时所在的位置算，被临时推开或悬停展开让出来的地方不算空位 |
| 缩放 | 拖边缘 / 角 | 拖动的边（含上下边）吸附到其他栅栏的边（齐平或隔开间距）和屏幕边缘，并显示参考线，碰到其他栅栏时正好停在隔一个间距处；拖上下边经过正好放下全部图标的高度时也停在那里（同样的吸附距离）；按住 Alt 不吸附。打开「调整大小时按整行整列对齐」后，离开这些边时宽度按整列、高度按整行；高度不是整行时各行均分多出的空间（和列均分宽度一样），任何高度都只显示完整的图标，图标大小、间距、视图不同的栅栏也能对齐；列表 / 详细信息视图宽度自由；收起时只能左右改宽 |
| 自动高度 | 栅栏选项（栅栏菜单 → 栅栏选项…，或 设置 → 栅栏）→ 自动高度（栅栏名称下面的第二项） | 高度跟随内容行数；内容增减时底边 250 ms 平滑过渡（阴影同步），应用启动 / 手动拖改时不动画 |
| 适应内容大小 | 双击栅栏的下边框；栅栏菜单 → 适应内容大小（在「锁定位置和大小」上面）；CLI `fence fit <栅栏>` | 高度调到正好放下全部图标，底边平滑过渡；打开「展开时把下面的栅栏推开」时下面的栅栏让开（同展开），关掉时最多长到下一个栅栏上方；收起、锁定、开了自动高度以及「像桌面一样排列」的「桌面」时菜单项是灰的，小工具栅栏没有这一项；日志记 `fit to content by=.. from_h=.. to_h=..` 或 `fit to content skipped reason=..` |
| 锁定 | 栅栏菜单 → 锁定位置和大小（锁定后同一项为「解除锁定」） | 边框不再是缩放区，标题仍可点、右键、双击 |
| 重命名 | 栅栏菜单 → 重命名… | 内嵌编辑框，Enter 确定 Esc 取消；F2 只重命名选中的图标，不重命名栅栏 |
| 删除栅栏 | 栅栏菜单 → 删除栅栏 | 项目回到「桌面」栏；「桌面」栏不可删（新文件和拖回桌面的图标都落在它里面）；删除前和 CLI `fence delete` 一样先存一份快照（菜单删除叫「删除栅栏前」，带上便签文字和脚本；快照已满且全是用户自己存的时不存）；菜单删除后右下角弹出「已删除栅栏“X”」卡片，点「撤销」或在栅栏上按 Ctrl+Z 把它找回来（位置、标签组、还在「桌面」栏的图标、指向它的规则、便签文字都回来）；已有别的提示卡片时不弹，Ctrl+Z 照样能用。不想看到「桌面」这个栅栏时：打开「像桌面一样排列」（再开「自由摆放」），它就不再是一个栅栏框，图标和 Windows 桌面上的一样，空着时什么也不显示；或者「为空时自动隐藏」；或者「Windows 桌面图标」选「显示，不显示“桌面”栅栏」（未归类的项目由 Windows 显示，但 Windows 会显示所有图标，栅栏里的也在）。只让未归类的图标作为 Windows 自己的图标留在桌面上做不到：Explorer 只能整体显示或隐藏桌面图标（反馈 #93、#117） |
| 撤销（Ctrl+Z） | 点一下栅栏（标题、边框或里面）后按 Ctrl+Z | 和桌面一样撤销最近一步：拖动栅栏、改大小（一起拖动的几个栅栏算一步）、把图标拖进或用菜单移到别的栅栏、从菜单删除栅栏；按住不放只撤销一步；最多记 20 步，只在内存里，退出、导入配置、恢复备份或快照、交换显示器后清空；删除文件、把文件移进文件夹这类文件操作交给 Windows 自己的撤销；命令行的改动不进撤销；没有可撤销的步骤时什么也不做；点栅栏标题或边框（Fluent 外观也一样）就让这个栅栏接收键盘，Delete、F2 等快捷键在拖动后直接作用于它 |

## 3. 标签页栅栏

| 功能 | 怎么用 | 备注 |
|---|---|---|
| 标签栏位置 | 设置 → 常规 → 标签栏位置（顶部 / 左侧；CLI `settings set tabBar left`） | 所有栅栏共用，默认顶部；左侧 = 有两个及以上标签页时，标签在栅栏左边从上到下排成一列，每个名字占一行（行高 32 DIP，行与行之间有细分隔线），当前标签有选中底色，标签色显示为名字前的小圆点，门户标签的向上按钮在当前标签那一行的右端；列宽按最长的名字定，96 到 160 DIP，最多占栅栏宽度的 45%（至少 96 DIP）；这一列代替标题行：栅栏不再有标题行，列的空白处可拖动栅栏、双击收起、右键打开栅栏菜单，别的栅栏拖到列上即合并，收起按钮在列的底部（悬停时显示）；收起时栅栏缩成只剩这一列，高度刚好放下全部标签（宽和高一起动画，圆角始终跟着窗口），收起按钮、当前标签的选中底色与加粗（门户的向上按钮也是）随之淡出，收起后各标签外观一样，单击任一标签即切到该标签并展开回原来的大小（双击的第二下不会再收起），保存的仍是展开时的位置和大小，悬停展开照常；「只给标题栏上色」只给这一列上色，「鼠标悬停时才显示标题栏」对这种栅栏不起作用；标签栏出现或变长时（合并、新增或改名标签、切换此设置），放不下全部标签的栅栏自动长高，到下方栅栏或屏幕底边为止（开启自动高度的栅栏始终把标签栏算进高度），之后仍可手动拖矮，标签按比例压缩；切换标签时新内容从上方或下方滑入 |
| 标签放不下时 | 自动（顶部标签条） | 标签保持自己的宽度（名字加内边距，最宽 160 DIP），标签条横向滚动；切换标签（点击、滚轮、Ctrl+Tab、速览搜索）时标签条 167 ms 滑到让当前标签完整露出的位置，当前标签和还有隐藏标签的一侧保持 28 DIP（露出下一个标签 16 DIP，再接 12 DIP 渐隐），窄到留不出时当前标签居中；被挡住的一端 12 DIP 渐隐；收起按钮隐藏时标签条延伸到按钮的位置，悬停标题、按钮淡入时同步缩回，标签不动；被挡住的部分不响应点击，悬停切换只对完整露出的标签生效；拖动标签或把别的栅栏拖到标签条两端 32 DIP 以内时，标签条以每秒 360 DIP 自动滚动；收起的栅栏只要放得下两个最窄的标签就显示项目数；左侧标签栏放不下时仍按比例压缩 |

## 5. 智能栅栏

栅栏里放一条保存的搜索：显示符合条件的文件，文件变了它跟着变。文件留在原处，不移动、不复制。

## 9. 小工具

设置 → 小工具：一个开关（`tools.enabled`，默认打开）管便签、时钟和脚本栅栏，关上后小工具栅栏不建窗口、不运行脚本，栅栏和内容保留，打开后回到原处；开关下面一张清单，每行一个按钮：便签与待办「新建便签」，时钟「添加」（桌面上已有时钟时按钮变灰，写「已在桌面上」），天气、GitHub 仓库动态、电脑状态「添加」，用自己的脚本「写法说明」（按界面语言打开使用手册的「自己写脚本栅栏」一课）和「选择脚本…」；按清单里的按钮或菜单项新建小工具时，开关关着就先打开它。开关打开时，托盘菜单和栅栏菜单有「新建便签」和「新建小工具」子菜单（时钟，桌面上已有时钟时不显示；天气、GitHub 仓库动态、电脑状态；用自己的脚本…）。小工具放在栅栏里，移动、吸附、改大小、收起、锁定、速览、双击桌面隐藏、外观（含全透明）都和普通栅栏一样；小工具栅栏不放图标，不参与标签页（不能合并，也不能被合并），不是整理规则的目标，拖放、粘贴、`item move --to` 都不会把项目放进去；栅栏菜单里没有视图、排序、新建、粘贴和标签页，换成各小工具自己的项目；设置 → 栅栏 也不显示图标大小、间距、名称、对齐、自动高度和「为空时自动隐藏」，CLI 设置这些属性或 `fence fit` 会返回错误；便签和脚本栅栏在外观里多一项「文字大小」，时钟的字跟着栅栏大小变（见下面各行）。

| 功能 | 怎么用 | 备注 |
|---|---|---|

复制文字（鼠标旁边显示「已复制」2 秒，复制失败时显示「复制失败，请重试」），`action=` 带着 `PECOFENCE_ACTION=<值>` 再运行一次脚本并显示新的输出，`refresh=true` 点完再运行一次（`run=` 的程序结束后再运行，最多等 60 秒）；一行有几个动作时按 href、open、run、copy、action `action=` 的待办点一下马上打勾或取消，以脚本下一次的输出为准；能点的行在鼠标下有浅色底板和手形指针，停留时显示脚本的 tooltip（没有时显示网址、路径、程序或要复制的文字），打开网址或文件的行在鼠标下右边还有小箭头；脚本还在运行时，点带 `action=` 或 `refresh=true` 秒限制；打印的每一行马上加到栅栏里，打印一行 `~~~` 表示换一屏：下一行打印出来时清掉栅栏原来的内容，之后的行再接着往下加，所以 `~~~` 写在每块内容前面（SwiftBar 的写法）或后面都行，旧内容一直留到下一行到来；栅栏保留最新的 40 行；Python 脚本另设 `PYTHONUNBUFFERED=1`；点带 `action=` ## 10. 明确不做

| 功能 | 原因 |

## 11. 多语言

设置 → 常规 → 语言 → 显示语言（常规页最上面），支持简体中文、繁体中文、英语、日语、韩语、德语、法语、西班牙语、葡萄牙语（巴西）、俄语和意大利语，并可跟随 Windows 显示语言。切换即时更新设置页、菜单及原生界面文字；已有文件名、栅栏名称、规则和快照名称保持不变。Windows 自带对话框和扩展菜单仍使用系统语言。详细说明见 [LOCALIZATION.md](LOCALIZATION.md)。
