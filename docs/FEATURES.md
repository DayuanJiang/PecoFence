# PecoFence 功能总表

以当前源代码为准。「怎么用」一列写的是默认操作方式；凡带「设置」的在托盘菜单 → 设置… 里，凡带「栅栏菜单」的是在栅栏标题栏或空白处右键，「栅栏选项」是栅栏菜单 → 栅栏选项…（即 设置 → 栅栏 页，逐个栅栏调整外观 / 布局 / 行为），「项目菜单」是在图标上右键。

## AI + CLI：把桌面配置交给助手

PecoFence 内置 `pecofence-cli`，Claude Code、Codex、Cursor 等能运行本地命令的 AI 助手可以读取现有设置，直接配置正在运行的 PecoFence。你可以让助手切换主题、批量调整透明度和图标大小、创建栅栏与标签页、整理图标、编写自动规则，以及导入导出配置。

启动 PecoFence 后，把需求交给助手，例如：“先阅读 `pecofence-cli skill` 和 `pecofence-cli describe`，查看并备份我的配置，再切换为深色模式，把所有栅栏调得更透明。”Microsoft Store 版通过 PATH 调用；便携版需告诉助手 `pecofence-cli.exe` 的完整路径。

JSON 输出报告实际改动，命令目录与 JSON Schema 帮助助手发现可用操作和参数。布局快照保存栅栏布局；全局设置和规则通过配置导入导出备份与恢复。详见 [CLI 上手指南与完整参考](CLI.md#start-with-your-ai-agent)。

## 1. 栅栏基础

| 功能 | 怎么用 | 备注 |
|---|---|---|
| 虚拟栅栏收纳桌面图标 | 首次启动自动建「程序 / 文件夹 / 文件与文档 / 桌面」四栏并按规则整理 | 整理不移动、不修改任何真实文件；真实桌面图标由 Explorer 同一开关隐藏，退出恢复，崩溃有 watchdog 兜底 |
| 新建栅栏 | 在空桌面上拖出一个矩形 → 「在此新建栅栏」；托盘菜单 / 栅栏菜单 → 新建栅栏 | 新栏放在源栏旁的空位，宽度正好整数列 |
| 移动 | 拖标题栏 | 与其他栅栏和屏幕边缘 8 px 吸附（设置可关）；吸附不累积，窗口始终在手底下 |
| 缩放 | 拖边缘 / 角 | 宽度按图标列整格吸附，高度按行整格吸附；列表 / 详细信息视图高度按行、宽度自由；卷起时只能左右改宽 |
| 自动高度 | 栅栏选项（栅栏菜单 → 栅栏选项…，或 设置 → 栅栏）→ 自动高度 | 高度跟随内容行数；内容增减时底边 250 ms 平滑过渡（阴影同步），应用启动 / 手动拖改时不动画 |
| 锁定 | 栅栏菜单 → 锁定位置和大小 | 边框不再是缩放区，标题仍可点、右键、双击 |
| 重命名 | 栅栏菜单 → 重命名…；或 F2 | 内嵌编辑框，Enter 确定 Esc 取消 |
| 删除栅栏 | 栅栏菜单 → 删除栅栏 | 项目回到「桌面」栏；「桌面」栏不可删 |
| 停靠到屏幕顶部 | 栅栏选项 → 停靠 | 贴顶、卷起、悬停展开 |
| 卷起 / 展开 | 双击标题；栅栏菜单 → 卷起 / 展开；点击右侧折叠箭头 | 带动画（展开 333 ms / 卷起 167 ms，WinUI Expander 曲线；内容 83 ms 交叉淡入淡出，Fluent 复用壁纸裁图，Liquid Glass 更新当前高度的折射边缘，阴影逐帧跟随）；折叠箭头随高度同曲线旋转 180°，项目数、标题省略点与标签条布局随卷起同步过渡（标签胶囊 167 ms 滑动，不再在结束时跳变）；卷起后标题右侧显示项目数；折叠箭头是独立按钮（悬停 / 按下有自己的底色，松开时触发，拖出去松开则取消），悬停标题时 83 ms 淡入，展开时项目数淡出 |
| 悬停展开 | 卷起的栅栏上悬停系统悬停时长（默认 400 ms）后自动展开，离开卷回 | 设置 → 卷起的栅栏悬停时自动展开；拖动文件在卷起的标题上停留同样时长也会展开（松手或离开后卷回） |
| 点击展开 | 设置 → 卷起的栅栏需点击标题才展开 | 打开后不再悬停展开，拖标题仍可移动 |
| 悬停才显示标题栏 | 设置 → 鼠标悬停时才显示标题栏 | 平时只有玻璃和图标；标题行 83 ms 淡入淡出 |
| 不活动时隐藏滚动条 | 设置 → 不活动时隐藏滚动条 | 鼠标在栏内、滚动后或离开后 2 s 内显示，83 ms 淡入淡出 |
| 快速隐藏 | 双击桌面空白处隐藏 / 再双击显示；托盘菜单 → 隐藏 / 显示所有栅栏；托盘图标双击 | 设置可关；第二击松开即切换（拖出框选则取消）；栅栏 167 ms 线性淡出 / 淡入，阴影（分层窗口常量 alpha）与栅栏同步淡入淡出 |
| 快速隐藏时保持可见 | 栅栏选项 → 快速隐藏时保持可见 | 单栏排除 |
| 显示桌面 (Win+D) 行为 | 设置 → 保持栅栏可见 / 随桌面隐藏 | |
| 浮现栅栏 (Peek) | 快捷键（默认 Ctrl+Alt+空格）；托盘菜单 → 浮现所有栅栏 | 所有栅栏浮到窗口之上，背景压暗（可关，83 ms 淡入 / 淡出，淡出期间再按热键即重新压暗）；再按热键、Esc、点击空处或切换窗口结束；Win+空格系列被 Windows 输入切换占用时自动回退并提示 |
| 多显示器 | 自动 | 几何按显示器归一化保存，分辩率 / 缩放 / 任务栏变化自动重排；每显示器独立布局 |
| 高 DPI | 自动 | 按显示器 DPI 渲染，登录时 96 DPI 漂移自动修正 |

## 2. 视图与外观

| 功能 | 怎么用 | 备注 |
|---|---|---|
| 图标大小 | 栅栏菜单 → 图标大小 → 小 / 中 / 较大 / 大；Ctrl+滚轮依次 32 → 48 → 64 → 96 | 小 / 中 / 大 = Windows 桌面的 32 / 48 / 96 px，较大 (64) 为兼容旧配置保留；设置里可定新建栅栏的默认值 |
| 图标间距 | 栅栏选项 → 图标间距 紧凑 / 标准 / 宽松 | |
| 视图样式 | 栅栏菜单 → 视图 → 图标 / 列表 / 详细信息 | 任何栅栏可用，不限门户 |
| 滚动 | 滚轮、键盘（方向键 / PageUp / PageDown / Home / End / 首字母跳选）、滚动条轨道点击（按住连续翻页）、滚动条箭头（按行，按住 200 / 50 ms 连续） | 平滑滚动（WinUI 规则：每 DIP 5 ms，50–1000 ms，滚轮上限 250 ms、键盘 / 翻页上限 333 ms，按住连续重复每步上限 83 ms 以免内容落后拇指，减速曲线），连续滚轮从目标位置累加；滚轮步长跟随 Windows「每次滚动行数」（列表 / 详细信息按行数，图标视图一行网格，「一屏」设置翻一屏）；精密触控板的亚格（|delta| < 120）增量 1:1 跟手、不做缓动；拖动拇指 / 按住轨道期间忽略滚轮与键盘滚动；系统关闭动画效果时直接跳转 |
| 悬浮滚动条 | 鼠标停在右侧 12 DIP 区域 | 停留 0.4 s 后 2→6 DIP 加宽（167 ms），同时 83 ms 淡入 12 DIP 轨道底色（LayerFill）与上下箭头按钮（Segoe Fluent Icons EDDB / EDDC 8 px，ControlStrong，悬停 SubtleFill 底色 + TextSecondary，按下 0.875 缩放），离开 0.5 s 后一起收窄淡出；拇指最短 30 DIP，行程排除两端 12 DIP 按钮；拖动 / 按住轨道立即加宽；系统关闭动画效果时不等延时直接改宽；拇指颜色始终为 ControlStrong（同 Windows 11） |
| 详细信息列 | 表头点击排序，再点倒序；拖分隔线改列宽；双击分隔线自动列宽；表头右键勾选 修改日期 / 类型 / 大小、恢复默认列宽 | 列宽按栅栏保存；窄栏自动收起列；表头单元有悬停 / 按下底色，松开时才排序（拖出去松开取消）；分隔线上的左右箭头光标由 WM_SETCURSOR 决定，不闪回箭头；排序箭头居中贴顶，标题一律次要色（同资源管理器） |
| 排序 | 栅栏菜单 → 排序方式 → 手动 / 名称 / 类型 / 修改日期 / 大小 / 打开次数，倒序 | 手动排序时可在栏内拖动图标调顺序（显示插入标记，83 ms 淡入淡出） |
| 布局动效 | 自动 | 新增 / 删除 / 重排 / 改排序时图标从旧格滑到新格（250 ms 点到点曲线），新项 167 ms 淡入，移除项原地 83 ms 淡出；切换标签、门户导航等大半内容更换时直接切换；跟随系统「动画效果」开关 |
| 图标载入 | 自动 | 异步取到的图标在灰色占位块上 167 ms 交叉淡入；缓存命中直接显示 |
| 选中项全名 | 单击 / 键盘选中某项 | 被选中（焦点）项的名称展开显示完整（最多 6 行，压在下一行之上，同 Windows 桌面）；重命名编辑框打开时不展开 |
| 主题风格 | 设置 → 常规 → 主题风格：Fluent / Liquid Glass | Fluent 为壁纸毛玻璃；Liquid Glass 保留清晰中心，在 8 DIP 圆角边缘向外折射壁纸，带轻微 RGB 色散、弧形高光和柔和阴影；文字依据壁纸亮度适配，图标标签有局部衬光；不采样其他窗口或视频壁纸 |
| 背景材质 | 所有栅栏跟随主题风格；栅栏选项可调整透明度与色调 | 壁纸变化自动跟随；旧配置保持 Fluent，云母和纯色旧值自动兼容；Liquid Glass 折叠时按当前高度重建边缘，Fluent 复用完整裁图 |
| 不透明度 | 栅栏选项 → 不透明度 更透明 / 默认 / 更厚实 | Fluent 默认以 55 % 不透明度绘制；Liquid Glass 默认显示完整的壁纸折射，避免原壁纸重影；更透明 = 更薄，更厚实 = 加一层实色 |
| 栅栏色调 | 栅栏选项 → 色调（9 色 / 无） | 标签页色条随之变色 |
| 标题颜色 / 字号 | 栅栏选项 → 标题颜色（跟随主题 / 跟随色调 / 白 / 黑）、标题字号（小 / 标准 / 大） | |
| 深浅色主题 | 设置 → 颜色模式：跟随 Windows / 跟随应用 / 浅色 / 深色 | 与主题风格独立保存，系统切换实时跟随 |
| 系统强调色 | 自动 | 选中、框选、拖放高亮、插入标记、托盘图标和设置页品牌色都取 Windows 个性化里的强调色（深色用 Light2、浅色用 Dark1，同 WinUI），改色实时跟随 |
| 状态过渡 | 自动 | 悬停 / 选中底色 83 ms 线性淡入淡出（悬停 SubtleFillColorSecondary、按下即时换成更浅的 SubtleFillColorTertiary，已选中项按下只显示选中底色，选中 + 悬停选中底色加深）；选中 / 悬停 / 焦点按项目身份跨排序、重排、重命名、文件夹刷新保留并随 250 ms 布局滑动；点击激活立即显示强调色；跟随系统「动画效果」开关，关闭即瞬切；每次只重绘变化的那一层 |
| 图标着色 | 设置 → 图标着色（颜色 + 强度） | 所有图标染色 |
| Chameleon | 设置 → 图标融入背景 | 图标降饱和、降不透明度 |
| 玻璃调参 | 环境变量 `PECOFENCE_ACRYLIC="不透明度,亮度锁定,模糊半径[,饱和度]"` | 仅影响 Fluent；Liquid Glass 原生材质验证可运行 `cargo run -p pecofence-render --example liquid_glass_preview -- .cache/glass.bmp` |

## 3. 标签页栅栏

| 功能 | 怎么用 | 备注 |
|---|---|---|
| 合并为标签页 | 把一个栅栏的标题拖到另一个栅栏的标题栏上松手（目标标题高亮，83 ms 淡入 / 167 ms 淡出）；或栅栏菜单 → 标签页 → 合并到… | 被合并的栅栏成为目标窗口里的一个标签；目标已有标签条时，指针所在槽位打开 96 DIP 插入空隙（邻居 167 ms 滑开，WinUI TabView 插入规则：过胶囊中线即下一格），松手落在该槽位，拖过末尾则追加；Esc 取消拖动即恢复原位、不合并 |
| 切换标签 | 点标签；Ctrl+Tab / Ctrl+Shift+Tab | 每个标签保留自己的图标大小 / 视图 / 排序和滚动位置（本次会话内）；当前标签加粗，其余常规字重；标签有悬停 / 按下底色；切换时旧内容 83 ms 淡出、新内容 83 ms 淡入并从新标签一侧滑入 24 DIP（167 ms），选中底色 167 ms 滑到新标签 |
| 重排标签 | 沿标签条左右拖；右键标签 → 左移 / 右移 | 被拖的标签跟着指针走，越过邻居中线即交换，邻居 167 ms 滑入空出的位置，松手后标签 167 ms 落回槽位；菜单左移 / 右移同样滑动；Esc 或按下右键取消并滑回原位；顺序持久化 |
| 拆出标签 | 把标签拖出标题行（上下 28 DIP 或拖出窗口）；右键标签 → 拆出为独立栅栏 | 新窗口出现在手底下并跟随鼠标；不松手拖回任一栅栏标题（含原窗口）即合并，落在标签条上时插入指针所在槽位（空隙实时跟随）；Esc 或按下右键取消，标签回到原来的位置 |
| 新建标签页 | 栅栏菜单 → 新建 → 标签页 | 当前窗口里加一个空栏 |
| 拖到标签头 | 把文件或图标拖到某个标签头上 | 直接放入那一页；标签头以选中色 + 强调色边框高亮（与文件夹目标一致，83 ms 淡入淡出）；停留不切换标签（与资源管理器一致）；拖到项目自己所在标签的标签头上显示「禁止」光标、不高亮（同目录拖放） |
| 双击标签 | 卷起 / 展开该窗口 | |

## 5. 项目操作（图标）

| 功能 | 怎么用 | 备注 |
|---|---|---|
| 打开 | 双击；Enter | 门户内的文件夹按上表规则导航或打开 |
| 选择 | 单击、Ctrl 多选、Shift 范围、框选（Shift 追加 / Ctrl 反选，越界自动滚动：逐帧、越远越快）、Ctrl+A、方向键 / Home / End / PageUp / PageDown、输入首字母跳选；Ctrl+方向键 / Ctrl+Home / End 只移动焦点不改选择，Ctrl+空格切换焦点项 | 多选后单击其一收缩为单选；键盘导航后焦点项显示双层焦点环（鼠标点击或失焦时消失）；栅栏不是活动窗口时选中色变为中性灰（167 ms 过渡，同资源管理器） |
| 栅栏间移动 | 拖到另一栅栏 / 标签头；项目菜单 → 移动到栅栏；拖回空桌面 = 放回「桌面」栏并立即按整理规则归类；从传送门拖到桌面由 shell 移动文件，监视器 60 ms 内对账归类；所有 shell 文件操作在工作线程执行，不阻塞动画 | 虚拟栏之间只改归属，不动文件；拖到内容区上 / 下边缘时自动滚动（越靠边越快） |
| 拖出到其他程序 | 把图标拖到资源管理器窗口、回收站、浏览器、其他程序 | 小选区（≤ 4 项且外接框 ≤ 320×320 DIP）的拖影是被选图标按屏幕上的排布渲染的位图，从原位起手（DI_GETDRAGIMAGE，同资源管理器）；更大的选区改用系统缩略图堆叠 + 数量角标，不遮住放置目标；源图标保持原样不变暗；移动 / 复制 / 链接光标，Ctrl 复制、Alt 或 Ctrl+Shift 创建快捷方式；Esc 取消 |
| 拖到文件夹图标上 | 拖到栅栏里某个文件夹图标上 | 移入该文件夹（Ctrl 复制、Shift 移动、Alt 或 Ctrl+Shift 创建快捷方式，与来源允许的效果一致；右键拖放弹出 移动 / 复制 / 创建快捷方式 / 取消 菜单），文件夹以选中色高亮（83 ms 淡入淡出）；拖影带资源管理器同款说明角标「移动到 <文件夹>」/「复制到 …」/「在 … 中创建链接」（DropDescription + IDropTargetHelper）；外来拖动悬停期间本栏已选项目变为中性灰 |

## 9. 多语言

设置 → 常规 → 显示语言，支持简体中文、繁体中文、英语、日语、韩语、德语、法语、西班牙语、葡萄牙语（巴西）和俄语，并可跟随 Windows 显示语言。切换即时更新设置页、菜单及原生界面文字；已有文件名、栅栏名称、规则和快照名称保持不变。Windows 自带对话框和扩展菜单仍使用系统语言。详细说明见 [LOCALIZATION.md](LOCALIZATION.md)。
