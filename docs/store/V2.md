## Campaign artwork and native screenshots

The five campaign compositions use newly captured native UI, with headlines,
backgrounds, crops and side-by-side states added outside the product. These files
live in `screenshots/<locale>/` outside `upload/`. They are useful for design review
and website or social promotion; do not use them in the Store screenshot fields.

Microsoft's [MSIX screenshot guidance](https://learn.microsoft.com/en-us/windows/apps/publish/publish-your-app/msix/screenshots-and-images),
checked September 23, 2026, says not to add logos, icons or marketing messages to
screenshots. The native upload images therefore only use a rectangular crop and
proportional resize. The separate hero artwork contains no text or fabricated app
controls; its original graphic studies echo the demonstration files.

## Rebuild

To render from the existing native captures:

```powershell
uv run --with pillow python scripts/make-store-v2.py
```

To prepare and capture fresh scenes on a Windows display of at least 2560 × 1440:

```powershell
uv run --with pillow --with numpy python scripts/prepare-store-v2.py
./scripts/capture-store-v2.ps1
uv run --with pillow python scripts/make-store-v2.py
```

The capture step displays temporary demonstration windows and then restores
focus. It requires the identified local fixture executable and WebView2 loader.
Original native captures and binaries are local build inputs, not included in
the source checkout.
