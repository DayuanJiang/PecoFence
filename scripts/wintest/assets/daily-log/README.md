# Daily log

Write what you are doing in the box and press Ctrl+Enter: the line goes, with the time, into
today's Markdown file in a folder you choose, for example `Documents\Log\2026-11\2026-11-16.md`.
The fence shows today's lines.

- Right-click the fence: 选择文件夹… chooses the folder (PecoFence asks you; the plugin can
  write only there), 把今天的记录移到回收站 moves today's file to the Recycle Bin.
- It writes Markdown files and makes one folder a month, nothing else, and sends nothing
  anywhere.
