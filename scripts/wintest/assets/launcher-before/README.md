# Launcher

Put the programs, files and folders you use often into this fence: drop them on it, or right-click it and
choose Add a program… or Add a file…. One click opens an item, as a fence icon opens. In the plugin's details you
can give the command Show the launcher a shortcut, and remove items.

The plugin knows each item by its name and picture only; PecoFence keeps where it is.
