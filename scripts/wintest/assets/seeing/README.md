# Seeing (test plugin)

The plugin of `scripts/wintest/tests/plugin-seeing.ps1`. It shows where the pointer, the keyboard focus
and the text caret are (the `pointer` and `focus` events, and `pf.pointer`, `pf.focus`, `pf.caret` once a
second), and the commands it got. Its command `show` brings the shortcut Ctrl+Shift+F9. It sends nothing
anywhere.
