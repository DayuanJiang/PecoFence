桌面与启动


随 Windows 启动

Windows 桌面图标
关闭 PecoFence 时保持 Windows 桌面图标隐藏
登录时 Windows 会先显示桌面图标，等 PecoFence 启动后才隐藏。打开后，退出或注销时图标保持隐藏，下次登录就不会闪现；PecoFence 没有运行时，桌面上不显示图标。要让图标重新显示，右键桌面，选“查看”→“显示桌面图标”

在桌面空白处拖出矩形时提供“在此新建栅栏”
矩形没有碰到任何栅栏时弹出这一项；关闭后拖出矩形只用来框选，仍可从托盘菜单新建栅栏

行为


锁定位置和大小
边框不再可拖动缩放；标题仍可点击、右键、双击

向上展开
上方放得下时向上展开，放不下就向下展开；标题栏留在原处。适合放在任务栏上方的栅栏

双击桌面隐藏时保留此栅栏
其他栅栏隐藏时，这个栅栏仍留在桌面上

为空时自动隐藏
里面没有图标时就不显示；桌面上一出现新图标，它会自己回来

像桌面一样排列
图标从屏幕左上角一列一列往下排，绕开其他栅栏，像 Windows 桌面的“自动排列图标”，不能随意摆放。关闭后“桌面”变回普通栅栏，可以移动和调整大小

停靠到屏幕顶部
贴到屏幕顶边并收起，鼠标悬停时展开，像一个下拉抽屉

双击文件夹或文件夹快捷方式时在此栅栏内打开
在栅栏里显示文件夹的内容，点向上箭头或按 Backspace 回到原来的图标


双击子文件夹时在此栅栏内打开
关闭后双击子文件夹改为在资源管理器中打开

标题栏显示文件夹图标
在标题前显示一个小文件夹图标

整理规则


新项目出现在桌面时自动归类
先看快捷方式目标规则，再按列表顺序匹配；都不符合的放进“桌面”栅栏

没有命中规则的项目
应用规则时，已在某个栅栏里但不符合任何规则的项目放在哪里；不符合规则的新项目总是放进“桌面”栅栏

立即对桌面上的全部项目应用规则
手动摆放过的项目保持原位

AI 助手


让 AI 助手整理桌面
能运行命令的 AI 助手（如 Claude Code、Codex）可以通过 pecofence-cli 查看桌面项目、新建栅栏、移动图标和添加规则

小工具

便签、时钟和脚本放在栅栏里，和普通栅栏一样可以移动、吸附和收起。关着的小工具不运行，也不占内存。


便签与待办
在栅栏里写几行字，单击就能编辑；行首写 [ ] 的那一行变成可以勾选的待办

时钟与日期
显示时间、日期和星期，时间格式跟随 Windows 的区域设置
显示秒
每秒更新一次

文件对话框


对话框跳转
打开或保存文件时，切到资源管理器再切回对话框，它就跳到资源管理器里的文件夹；点文件夹栅栏或按 Ctrl+G 也能跳过去

自己写的小工具


脚本栅栏
运行你选的脚本（PowerShell、Python、批处理等），把它打印的文字显示在栅栏里：可以每隔 1 分钟到 3 小时运行一次，也可以一直运行、几秒更新一次；脚本还可以让一行变得能点，点一下打开网址、运行程序或者给待办打勾。适合天气、倒计时、服务器状态，也可以让 AI 助手帮你写。PecoFence 不会为脚本栅栏联网，联网的是你的脚本
脚本最多运行 10 秒（标为一直运行的除外），不弹出窗口；运行间隔在栅栏的右键菜单里改
