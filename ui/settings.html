桌面与启动


随 Windows 启动

隐藏 Windows 桌面图标
桌面项目只显示在栅栏里，未归类的进入“桌面”栅栏；回收站等系统图标也会出现在“桌面”栅栏中
显示 Windows 桌面图标时隐藏“桌面”栅栏
未归类的项目只留在 Windows 桌面上；关闭“隐藏 Windows 桌面图标”后可用

双击桌面空白处隐藏或显示栅栏

临时显示 Windows 桌面
按快捷键隐藏所有栅栏、显示 Windows 桌面图标，再按一次恢复；托盘菜单里也有这一项
快捷键

在桌面空白处拖出矩形时提供“在此新建栅栏”
矩形没有碰到任何栅栏时弹出这一项；关闭后拖出矩形只用来框选，仍可从托盘菜单新建栅栏


行为



鼠标移开后自动收起

开启后不再悬停展开；拖动标题仍可移动栅栏


收起后它们会回到原位

鼠标悬停时才显示标题栏



标题栏只显示名称；双击标题或用右键菜单收起和展开


鼠标在标签页上停留片刻就切换过去，不用点击

自动隐藏滚动条
鼠标移到栅栏上或滚动时才显示

宽度按整列、高度按整行；关闭后可自由调整大小，图标自动铺满

栅栏

外观、锁定和自动高度对整组标签页生效

桌面上还没有栅栏。可以从托盘菜单新建，或在桌面空白处拖出一个矩形。











整理规则


新项目出现在桌面时自动归类
先看快捷方式目标规则，再按列表顺序匹配；都不符合的放进“桌面”栅栏

没有命中规则的项目
应用规则时，已在某个栅栏里但不符合任何规则的项目放在哪里；不符合规则的新项目总是放进“桌面”栅栏

立即对桌面上的全部项目应用规则
手动摆放过的项目保持原位
